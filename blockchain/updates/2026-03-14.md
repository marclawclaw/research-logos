- Poseidon2 compression update: cuts proving times in half
- This is a real bottleneck — 0.3 TPS on a high-end GPU is very low for production use

### 6. Sovereign Rollups vs Ethereum L2s
Key insight from blog post: on Ethereum, most users actually use non-canonical bridges (e.g., LayerZero) rather than the canonical bridge. This undermines the security rationale for L1-validated rollups. Logos' Sovereign Rollup model skips L1 validation entirely and lets rollup validators determine canonical state — aligns with how users actually behave.

### 7. SDP & SRDP Near-Complete
Service Declaration Protocol and Service Reward Distribution Protocol were nearly complete as of November 2025. These handle node operator registration and reward distribution for Bedrock Services.
