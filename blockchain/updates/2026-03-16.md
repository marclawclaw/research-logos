### 3. How to Join the Devnet (v0.2.1)

**Step 1 — Download circuits + binary** from GitHub releases (platform-specific archives):
```bash
mv logos-blockchain-circuits ~/.logos-blockchain-circuits
tar -xzf logos-blockchain-node-<version>-<arch>.tar.gz
```

**Step 2 — Init node** (connects to bootstrap peers):
```bash
./logos-blockchain-node init \
  -p /ip4/65.109.51.37/udp/3000/quic-v1/p2p/12D3KooWL7a8LBbLRYnabptHPFBCmAs49Y7cVMqvzuSdd43tAJk8 \
  -p /ip4/65.109.51.37/udp/3001/quic-v1/p2p/12D3KooWPLeAcachoUm68NXGD7tmNziZkVeMmeBS5NofyukuMRJh \
  -p /ip4/65.109.51.37/udp/3002/quic-v1/p2p/12D3KooWKFNe4gS5DcCcRUVGdMjZp3fUWu6q6gG5R846Ui1pccHD \
  -p /ip4/65.109.51.37/udp/3003/quic-v1/p2p/12D3KooWAnriLgXyQnGTYz1zPWPkQL3rthTKYLzuAP7MMnbgsxzR
# Produces user_config.yaml
```

**Step 3 — Run:**
```bash
./logos-blockchain-node user_config.yaml
```
Node writes rotating hourly log files.

**Step 4 — Verify:**
```bash
curl -w "\n" http://localhost:8080/cryptarchia/info
# Should show Bootstrapping → Online, slot + height increasing
```

**Step 5 — Get funds (faucet):**
- Find wallet key: `grep -A3 known_keys user_config.yaml`
- Visit https://devnet.blockchain.logos.co/web/faucet/
- Requires credentials from Logos team (ask on Discord: #1468535289604735038)
- One request per block — wait for balance to update before requesting again

**Step 6 — Block production:**
- ~3.5 hours (two epochs) after receiving funds, node automatically starts proposing blocks

**Step 7 — Inscribe messages:**
```bash
./logos-blockchain-node inscribe
```
