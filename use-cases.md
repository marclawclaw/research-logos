# Use Cases, RFPs & Applications

> Last updated: 2026-03-14

## Applications Being Built on Logos

### 1. Status (Primary Consumer)
The most significant application using Logos technologies. Status is a blockchain-based app combining messaging, wallet, DApp browser, and community tools.

- **Uses Waku/Messaging** for censorship-resistant chat
- nwaku being integrated into Status Desktop (replacing go-waku)
- Status Network is an Ethereum L2 with public goods funding
- Messaging reliability testing done in partnership with Vac QA

**Source:** [free.technology](https://free.technology)

### 2. OpChan
Privacy-preserving communications platform integrating Waku protocols:
- Showcases Logos technologies
- Emphasizes censorship resistance and community self-sovereignty

**Source:** [Logos network search results](https://press.logos.co)

### 3. Censorship-Resistant File Sharing
Demo application combining **Codex + Waku**:
- Demonstrated at IFT meetup (April 2025)
- Shows cross-component integration potential
- Tools ready for early builders on testnet

**Source:** [press.logos.co/article/april-2025](https://press.logos.co/article/april-2025)

### 4. Safe Harbour
Decentralized multisig operations using Waku for communication:
- Threshold Access Control for encrypted communications
- Multi-signature wallet coordination

**Source:** [press.logos.co/article/2025-dev-retrospective](https://press.logos.co/article/2025-dev-retrospective)

### 5. Sovereign Zone Prototypes
Two working proofs of concept for applications on Nomos Sovereign Zones:
- zkEVM rollup with state transitions verified by light clients
- Demonstrated at April 2025 offsite

**Source:** [blog.nomos.tech/2025-year-in-review](https://blog.nomos.tech/2025-year-in-review/)

### 6. Logos Basecamp
Complete distribution bundling the kernel, default modules, and UI packages:
- Wallet functionality
- Chat interface
- File-sharing tools
- Explorer functionality
- Available via GitHub

**Source:** [build.logos.co](https://build.logos.co)

## Analysis

### Observations
- **Status dominance:** Status is by far the most significant consumer of Logos tech. This is both a strength (real-world usage) and a risk (single major user)
- **Early-stage ecosystem:** Beyond Status, the application ecosystem is primarily demos and prototypes
- **RFP program is small:** Only 2 RFPs publicly listed — this is very early-stage compared to ecosystems like Ethereum Foundation grants
- **No Lambda Prize found:** Despite being mentioned in the research brief, no Lambda Prize program was discoverable in current public sources
- **Community-driven ideas:** The ideas board approach is good for engagement but lacks the funding mechanisms of more mature grant programs
