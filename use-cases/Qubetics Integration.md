# Qubetics × Codex Integration

## Summary

In August 2025, Codex collaborated with **Qubetics** — an AI-centric product stack — to integrate Codex decentralised storage for AI model data persistence. The initial use case stored **QubeQobe libraries in SLM (Small Language Model) format on Codex**.

## What Qubetics Does

Qubetics is building an AI product infrastructure stack. The integration with Codex focused on using decentralised storage for:
- Storing AI model libraries (SLM/QubeQobe format)
- Enabling censorship-resistant and durable AI artifact storage
- Demonstrating decentralised AI (DAI) patterns where model data is stored outside centralised cloud providers

## Key Points

- **SLM format** — Small Language Model artifacts, lightweight AI models optimised for edge/constrained environments
- **QubeQobe** — Qubetics' library format for their AI model components
- First known integration of Codex with an AI product company's live model storage

## Why It's Significant

This is the first confirmed production-style integration of Codex with an AI company, validating the **Codex AI use case thesis**:
- AI training data and model artifacts can live on decentralised storage
- Immutable CIDs provide provenance for AI model versions
- Censorship-resistant storage means no single cloud provider can remove access

## Context: Codex's AI Thesis

Codex has been articulating AI as a major use case since early 2025:
- AI models and datasets need durable, scalable, transparent storage
- Decentralised storage enables accountability for training data provenance
- Federated learning workflows benefit from decentralised data access

See [[Codex AI Use Cases]] for the full thematic breakdown.

## Codex Evolution Note

As of August 2025, Codex paused its current testnet to undergo architectural rework ("Codex is Evolving" — Codex July/August 2025 update). The core mission remains the same: censorship-resistant, developer-friendly storage protocol. A new testnet is expected after the architectural redesign.
