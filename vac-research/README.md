## Quick Summary

Vac is the **R&D backbone of IFT** (the Logos ecosystem). Nine specialized service units cover:
- P2P networking (nim-libp2p, GossipSub)
- Cryptography & ZK (RLN, zerokit, Nescience)
- Token economics, smart contracts, QA, DST, Nim tooling, RFC/specs, security

All specs now live at **lip.logos.co** (was rfc.vac.dev). The main research site is **research.logos.co** (was vac.dev).
